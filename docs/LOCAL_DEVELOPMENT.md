# Локальная разработка с PostgreSQL на Seller VM

Локально запускаются FastAPI, sync worker и Vue. На VM находятся PostgreSQL и инфраструктурные контейнеры. Отдельный Redis не нужен: долговечная очередь синхронизации хранится в собственной базе Seller.

## Первый запуск

1. Скопируйте выданный для окружения `.env.dev`. Не коммитьте этот файл.
2. В `api` создайте виртуальное окружение и зависимости:

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

3. В `web` установите зависимости:

   ```bash
   npm ci
   ```

4. В VS Code запустите задачу `Seller: открыть SSH-туннель PostgreSQL` и оставьте её работающей.
5. Запустите `Seller: запустить API локально`, `Seller: запустить worker локально`, затем `Seller: запустить web локально`.

После этого браузер открывает адрес, который выводит Vite; UI обращается к локальному API через `/api`, а API — к `127.0.0.1:5434` в SSH-туннеле.

## Безопасность туннеля

На VM PostgreSQL опубликован только на `127.0.0.1:5434`. Он недоступен из интернета. SSH-туннель пробрасывает этот loopback-порт также только на локальный `127.0.0.1:5434`.

После завершения разработки остановите задачу туннеля. Никогда не публикуйте PostgreSQL на `0.0.0.0` и не добавляйте порт базы в firewall.
