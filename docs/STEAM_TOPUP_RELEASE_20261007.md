с правами 700. При финальной проверке выявлен временный HTTP 403. Веб-образы
возвращены к предыдущим, права в новых образах исправлены: директории 755,
файлы 644. Перед повторным переключением проверен реальный GET / внутри

и браузер. Файлы приложения не менялись. Итоговые образы имеют suffix staticfix.

reload ещё использовал прежние маршруты (POST возвращал 405). Пересоздание
только gateway обновило mount; checksum Caddyfile и публичные POST проверены.
Эти ошибки поставки не затронули API покупки, worker заказов, CRM и данные.

итоговая запись после исправления статики; deployment.json описывает первый
проход. На Hub/Seller дополнительно database-before.dump (права 600; проверен

восстановление production dump в этом релизе не выполнялось; миграции проверены
отдельно в синтетических БД. Секреты остались только на соответствующем сервере.

Предыдущие образы помечены steam-before-<container-name>:20261007.
Пока Steam выключен и операций нет, откат выполняется восстановлением прежних
тегов из previous-images.json, соответствующих исходников из source-backup
(или предыдущего Git commit для Seller/сайта) и пересозданием только изменённых
сервисов. Аддитивные таблицы/колонки не удалять. После будущего включения
при payment_started/unknown сначала нужна сверка операции; нельзя откатывать
на старый Hub, который не понимает steam_topup.
